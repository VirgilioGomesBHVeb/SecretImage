Sobre o SecretImage 2.0

Uma plataforma académica de criptografia e esteganografia.

O que é?

O SecretImage 2.0 protege uma mensagem com uma chave e depois esconde o conteúdo cifrado dentro de uma imagem através de esteganografia LSB.

Python + Flask Servidor e lógica da aplicação.
Cryptography / Fernet Protecção da mensagem.
Pillow + LSB Processamento e esteganografia da imagem.
HTML + CSS + JavaScript Interface e interacções.
